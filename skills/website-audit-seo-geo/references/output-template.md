# Output Template

Fill this skeleton. Keep findings tied to evidence and business impact.

## 1. Executive Summary

- Overall grade: A–F
- Biggest strengths
- Biggest weaknesses
- What matters most now
- Main risk area: SEO / GEO / entity / design / conversion / performance / accessibility
- Highest-ROI opportunity

## 2. Dimension Scorecard

One row per dimension, same treatment for all — no dimension gets a special section.

| Dimension | Grade |
|---|---|
| Technical SEO | A–F |
| AI Search / GEO | A–F |
| Entity Strength | Strong / Moderate / Weak / Absent |
| Citation Readiness | Strong / Moderate / Weak / Absent |
| Content Authority | Strong / Moderate / Weak / Absent |
| Design | A–F |
| Trust | A–F |
| Conversion Readiness | Strong / Moderate / Weak / Absent |
| Performance | A–F |
| Accessibility | A–F |

## 3. Key Findings

Ordered by business impact. Every specific problem goes here, design included. Per finding:

- Priority · Type · Issue · Status
- Production/code status (if repo exists)
- Why it matters
- Evidence
- Exact URL
- Exact file path (if repo exists)
- Recommended fix
- Impact · Effort · Confidence

Caps unless exhaustive coverage is requested: ≤5 medium, ≤3 low.

## 4. Quick Wins

Top 5 highest-impact, lowest-effort fixes across any dimension.

## 5. Strategic Opportunities

High-leverage only: citation-ready pages, entity clarity, proof architecture, service-page structure, topic clusters, internal linking, commercial-page upgrades, design modernization, conversion improvements tied to business goals.

## 6. False Alarms / Already Fine (mandatory)

Proper redirects, canonicalized alternates, already-live fixes, harmless platform behavior, historical issues absent from production, low-priority distractions.

## 7. Prioritized Action Plan

- **Do First** — highest impact, lowest risk
- **Do Next** — meaningful, less urgent
- **Defer** — real but can wait

## 8. Code Changes (only if repo access exists)

Exact files, snippets, metadata/schema examples, component changes, deployment notes, what's ready to ship vs. what needs testing first.
